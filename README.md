# 🍅 Sabor da Casa — Cardápio Digital

Site de demonstração de restaurante com **cardápio digital e pedido via
WhatsApp**. O cliente escolhe os pratos, monta o carrinho e envia o pedido
pronto para o número da loja — sem sistema de pedidos, sem mensalidade de
plataforma.

> 📄 Demo publicada: [VER AQUI](https://jon4s118.github.io/Sabor-da-casa/)

## 🎯 Objetivo do projeto

Projeto de portfólio que demonstra na prática o serviço oferecido: sites
rápidos e funcionais para negócios locais, criados com apoio de inteligência
artificial e revisados manualmente.

## ⚙️ Funcionalidades

- Cardápio organizado por categoria (pratos e bebidas)
- Carrinho de pedidos com adicionar/remover itens
- Total calculado automaticamente
- Pedido formatado e enviado direto no WhatsApp do restaurante
- Layout responsivo (pensado primeiro para celular)
